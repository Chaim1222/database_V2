# אימות זהות למועמדי העברה

שם ישן יכול להתפס מחדש אחרי העברה. הדוח אינו מסיר מועמד רק מפני שקיים היום דף ויקיפדיה באותו שם: הגרסה שבתבנית עשויה להיות שייכת לדף המקורי שהועבר.

movecheck בודק רק מועמדי העברה, כולל מועמדים שהוסתרו בהצלחה קודמת. הוא קורא את התבנית החיה לפי מזהה המכלול, מאמת שהגרסה המקומית והמקור תואמים לצילום template_check, ומבקש מוויקיפדיה את זהות גרסת המקור. רק דף חי במרחב הראשי ששמו תואם לשדה דף הוא הוכחה. ההוכחה נשמרת בנפרד מההתאמות; אין שינוי ב-template_link, שיוך ידני או חישוב חסרים.

הדוח מסיר מועמד היסטורי רק כשהוכחה תקפה מציינת מזהה מקור אחר. שינוי בגרסה המקומית, גרסת המקור או שדה דף בסנכרון מבטל את ההוכחה. denied או העדר הוכחה אינם מסירים מועמד. תשובת API חסרה/שגויה מפילה את האימות בלי לייצר הוכחה חדשה. המידע נשען על הסנכרון האחרון; עריכה שטרם סונכרנה אינה נראית למסד.

## החלה אחרי מיזוג

1. להחיל מיגרציה 0036 דרך workflow המיגרציות.
2. להריץ עדכון שינויים מהאתרים; נוסף בסופו שלב movecheck. גם workflow התחזוקה כולל את השלב. התחזוקה עצמה אינה מסנכרנת מראה, ולכן אחרי עריכה באתר מתחילים בסנכרון.
3. לוודא שמקדש קונקורדיה החדש (1178550) אינו מופיע בהעברות. דפים אמיתיים שטרם טופלו צריכים להישאר.

אפשר להריץ בנפרד: python -m collector.cli movecheck.

בדיקות: unittest discover -s tests; db/run_tests.sh. בדיקת t30 משחזרת יצירה בשם שנתפס מחדש, ומשווה הוכחה טרייה, מקור זהה, מידע מיושן, denied והרשאות.
