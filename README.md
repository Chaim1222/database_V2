# database_v2: מערכת ההשוואה ויקיפדיה ↔ המכלול, מבוססת צרכים

כתיבה מחדש של המסד, הצינורות והדשבורד, אחרי הלמידה על המערכת הקודמת (`Chaim1222/database`).

**התכנון המלא:** [`DESIGN.md`](DESIGN.md). **מצב:** שלב 1 (מיגרציות המסד ובדיקות) בוצע מקומית; הקולקטור והדשבורד טרם נכתבו. שום פרויקט סופרבייס עוד לא מחובר.

## הרצת בדיקות המסד

```
db/run_tests.sh          # מיגרציות + בדיקות SQL על Postgres 16 מקומי (מסד זמני)
db/perf/run_scale.sh     # מדידת גודל וזמנים על נתונים סינתטיים בגודל הייצור
```

דורש `psql` ו-Postgres 16 (בסביבה כאן: `pg_ctlcluster 16 main start`).

## מבנה

- `db/migrations/`: מיגרציות קדימה בלבד, ממוספרות.
- `db/tests/`: בדיקות SQL (נרמול הכותרת מול Python, מראות, נגזרים, הרשאות, views).
- `db/perf/`: מדידות קנה מידה.
