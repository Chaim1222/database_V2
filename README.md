# database_v2: מערכת ההשוואה ויקיפדיה ↔ המכלול, מבוססת צרכים

כתיבה מחדש של המסד, הצינורות והדשבורד, אחרי הלמידה על המערכת הקודמת (`Chaim1222/database`).

**התכנון המלא:** [`DESIGN.md`](DESIGN.md). **מצב:** שלב 1 (מיגרציות המסד ובדיקות) בוצע ומוחל על פרויקט סופרבייס `database_V2` (`ukzijtrpchvmoxlslxpz`), שעדיין ריק. הקולקטור והדשבורד טרם נכתבו.

## הרצת בדיקות המסד

```
db/run_tests.sh          # מיגרציות + בדיקות SQL על Postgres 16 מקומי (מסד זמני)
db/perf/run_scale.sh     # מדידת גודל וזמנים על נתונים סינתטיים בגודל הייצור
```

דורש `psql` ו-Postgres 16 (בסביבה כאן: `pg_ctlcluster 16 main start`).

## מבנה

- `db/migrations/`: מיגרציות קדימה בלבד, ממוספרות.
- `db/tests/`: בדיקות SQL (נרמול הכותרת מול Python, מראות, נגזרים, הרשאות, views).
- `db/perf/`: מדידות קנה מידה.

## מיגרציות בסופרבייס

הקבצים ב-`db/migrations/` הם המקור. ההחלה דרך ה-MCP של סופרבייס שומרת את הטקסט בלי הערות, ורושמת ב-`supabase_migrations.schema_migrations` (גרסאות `0001` עד `0006`). אחרי כל החלה: בדיקת עשן בתוך `do $$ ... raise exception ... $$` (מתגלגל לאחור), ו-`get_advisors`.

הערות מה-advisor (5.10): ב-6 טבלאות RLS מופעל בלי מדיניות, **בכוונה** (סגורות ל-anon/authenticated; רק service_role).
